# Rio API Indicadores Públicos

Projeto de portfólio voltado ao consumo de APIs públicas para análise de indicadores urbanos do município do Rio de Janeiro.

A proposta é construir uma base analítica a partir de dados públicos relacionados a saúde, educação e segurança pública, aplicando etapas de coleta, tratamento, padronização, enriquecimento e documentação dos dados.

## Objetivo

Consumir dados públicos por meio de APIs e endpoints abertos, transformando essas informações em uma base organizada para análise territorial do município do Rio de Janeiro.

## Temas do projeto

- Saúde pública
- Educação
- Segurança pública
- Indicadores urbanos
- Dados territoriais do município do Rio de Janeiro

## Tecnologias previstas

- Python
- Pandas
- Requests
- APIs públicas
- Jupyter Notebook
- GitHub

## Etapas planejadas

1. Identificação das fontes públicas de dados
2. Consumo das APIs com Python
3. Tratamento e padronização dos dados
4. Enriquecimento das bases
5. Criação de indicadores
6. Documentação das regras utilizadas
7. Análise exploratória dos resultados

## Fontes previstas
