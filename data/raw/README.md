# Dados Brutos

Esta pasta será utilizada para armazenar os dados brutos coletados diretamente das APIs públicas utilizadas no projeto.

Os arquivos desta pasta representam os dados em seu formato inicial, antes das etapas de tratamento, padronização e enriquecimento.

## Observação

Os dados serão gerados a partir dos scripts Python localizados na pasta `src`.

Exemplo previsto:

- `bairros.csv`: arquivo gerado a partir da coleta da API pública de limites de bairros do município do Rio de Janeiro.
