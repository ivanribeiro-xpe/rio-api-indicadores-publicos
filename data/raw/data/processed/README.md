# Dados Tratados

Esta pasta será utilizada para armazenar os dados processados no projeto.

Os arquivos desta pasta serão gerados após as etapas de tratamento, padronização e enriquecimento dos dados brutos coletados por API.

## Exemplos previstos

- Dados de bairros padronizados
- Dados de saúde tratados
- Dados de educação tratados
- Bases enriquecidas para análise
