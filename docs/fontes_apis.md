# Fontes de APIs

Este documento reúne as fontes públicas previstas para o projeto Rio API Indicadores Públicos.

## Objetivo

Registrar as APIs e endpoints públicos utilizados no projeto, indicando a finalidade de cada fonte e os dados que serão consumidos.

## Fontes previstas

### DATA.RIO

Fonte prevista para dados públicos do município do Rio de Janeiro, incluindo bases territoriais, equipamentos públicos, saúde e educação.

Uso previsto no projeto:

- Limites territoriais
- Bairros
- Escolas municipais
- Unidades de saúde
- Dados urbanos do município do Rio de Janeiro

### ISP Dados Abertos

Fonte prevista para dados de segurança pública do Estado do Rio de Janeiro.

Uso previsto no projeto:

- Indicadores mensais de criminalidade
- Séries históricas
- Dados por município
- Dados por áreas de segurança pública, quando aplicável

## Observações metodológicas

As fontes serão avaliadas quanto à disponibilidade, granularidade territorial, periodicidade de atualização e compatibilidade entre os dados.

Quando não houver correspondência direta entre bairro, município, região administrativa ou área de segurança pública, a limitação será documentada no projeto.
